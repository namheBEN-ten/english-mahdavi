# آکادمی زبان استاد مهدوی

نسخه استاتیک مناسب GitHub و Cloudflare Pages؛ شامل ثبت‌نام/ورود ایمیل و رمز عبور، دوره‌ها و درس‌های نمونه، پنل زبان‌آموز و پنل مدیریت.

## مهم قبل از انتشار
- سایت برای احراز هویت و ذخیره‌سازی واقعی به Supabase نیاز دارد.
- قیمت‌ها فقط اطلاعات نمایشی هستند؛ درگاه پرداخت در این نسخه پیاده‌سازی نشده است.
- کلید `service_role` یا `secret` را هرگز در `config.js` قرار نده. فقط URL پروژه و کلید عمومی `publishable`/`anon` را وارد کن.
- عکس استاد در `assets/ostad-mahdavi.jpg` قرار دارد.

## راه‌اندازی Supabase
1. در Supabase یک پروژه بساز.
2. از بخش SQL Editor، تمام محتوای `supabase-setup.sql` را اجرا کن.
3. از Project Settings → API (یا Connect) آدرس پروژه و کلید عمومی publishable/anon را بردار.
4. فایل `config.js` را باز کن و مقادیر زیر را وارد کن:

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://YOUR-PROJECT.supabase.co",
  SUPABASE_ANON_KEY: "YOUR_PUBLIC_PUBLISHABLE_OR_ANON_KEY"
};
```

5. در Supabase → Authentication → URL Configuration، آدرس سایت نهایی Cloudflare Pages را به Site URL و Redirect URLs اضافه کن. اگر تأیید ایمیل فعال است، زبان‌آموز باید ایمیل تأیید را باز کند.
6. پوشه‌ها و فایل‌های همین پروژه را در ریشه مخزن GitHub قرار بده (خود پوشه `mahdavi-academy` را باز کن و محتویاتش را آپلود کن) و Cloudflare Pages را به مخزن وصل کن. Build command خالی و output directory برابر `.` باشد.

## فعال‌کردن پنل مدیریت
1. اول از فرم سایت با ایمیل خودت یک حساب بساز.
2. در Supabase → SQL Editor، دستور زیر را اجرا کن و ایمیل خودت را جایگزین کن:

```sql
update public.profiles
set role = 'admin'
where email = 'YOUR-EMAIL@example.com';
```

3. از سایت خارج شو و دوباره وارد شو. گزینه «پنل مدیریت» ظاهر می‌شود.

نقش مدیر از سمت دیتابیس کنترل می‌شود؛ هیچ فرم عمومی برای مدیرکردن حساب‌ها وجود ندارد.

## امکانات پنل مدیریت
- افزودن، ویرایش، حذف و انتشار/پیش‌نویس دوره‌ها
- تغییر عنوان، توضیحات، سطح، مدت، قیمت و نشانی تصویر دوره
- افزودن، ویرایش و حذف درس‌ها و متن آموزشی هر درس
- مشاهده حساب‌های ثبت‌نام‌شده و فعال/لغو کردن دسترسی به دوره‌ها

## محدودیت‌ها
- درگاه پرداخت، ایمیل‌های اختصاصی/SMTP، آزمون و ویدئوها در این نسخه پیاده‌سازی نشده‌اند.
- دوره‌های رایگان با ثبت‌نام در دسترس‌اند؛ برای دوره‌های غیررایگان، مدیر باید دسترسی را دستی فعال کند تا وقتی درگاه پرداخت امن اضافه شود.
- سایت به‌صورت استاتیک میزبانی می‌شود؛ داده‌های کاربران و دوره‌ها در Supabase نگهداری می‌شوند.

## امکانات افزوده‌شده در نسخهٔ ارتقایافته
- تصاویر محلی برای دوره‌های پایه، مکالمه، گرامر و آیلتس؛ در صورت نداشتن نشانی تصویر، تصویر مناسب بر اساس عنوان انتخاب می‌شود.
- سبد خرید سمت کاربر با افزودن و حذف دوره و محاسبه مجموع، ذخیره‌شده در همان مرورگر.
- پرداخت آنلاین و ثبت سفارش نهایی هنوز پیاده‌سازی نشده است؛ برای فروش واقعی به جدول سفارش‌ها و درگاه پرداخت امن نیاز است.
